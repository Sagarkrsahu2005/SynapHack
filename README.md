# SynapHack | HeAR AI (Frontend Showcase)

A modern, visually engaging frontend project simulating an AI-powered healthcare tool for cough sound analysis.

---

## Overview

This project is a **frontend-only showcase** designed to demonstrate advanced web development skills, including responsive layouts, interactive UI elements, animations, and creative use of multimedia. The site presents a fictional AI tool, "HeAR," which analyzes cough sounds for early disease detection, as part of the SynapHack 2025 theme.

---

## Features

- **Modern, Responsive Design:** Built with HTML, CSS, and JavaScript.
- **Rich Animations:** Includes loaders, animated SVGs, and 3D elements (via Spline).
- **Interactive UI:** Simulated chat interface, video backgrounds, and dynamic cards.
- **Media Integration:** Uses images and videos for an immersive experience.
- **Thematic Content:** All content and flows are designed for demonstration purposes.
