# SynapHack | HeAR AI (Frontend Showcase)

A modern, visually engaging frontend project simulating an AI-powered healthcare tool for cough sound analysis.

## Overview

This project is a **frontend-only** showcase, designed to demonstrate advanced **web development** skills and cutting-edge technologies such as **React**, **Next.js**, **JavaScript**, **CSS**, and **Spline**. The site presents a fictional AI tool, **"HeAR"**, which analyzes cough sounds for early disease detection, in line with the **SynapHack 2025** theme of **AI in healthcare**.

## Technologies Used

- **React.js**: Leveraged to create dynamic, reusable components and manage state efficiently.
- **Next.js**: Used for server-side rendering, static site generation, and optimizing performance.
- **CSS** & **Tailwind CSS**: Ensured a responsive and sleek design, with utility-first CSS for quick styling.
- **JavaScript**: For interactive functionalities, data handling, and animations.
- **Spline**: Incorporated for 3D animations and interactive visuals to enhance user engagement.
- **API Integration**: Potential future integration for simulating real-time cough analysis (mocked API used for the demo).

## Features

- **Modern, Responsive Design**: Built with **React** and **Next.js** for optimal performance and SEO, ensuring a smooth experience on both mobile and desktop.
- **Rich Animations**: Includes loaders, animated SVGs, and **3D elements** from **Spline** for immersive transitions and interactions.
- **Interactive UI**: Features a simulated chat interface for user interaction, dynamic cards that update based on user input, and **video backgrounds** for added flair.
- **Media Integration**: Uses images and videos to provide an engaging and realistic healthcare experience, where users interact with simulated AI outputs.
- **AI Simulation**: Presents simulated AI-powered features for analyzing cough sounds, demonstrating potential future integration with **real AI models**.
- **Smooth Navigation**: Utilizes React Router for seamless transitions between sections, and custom hooks to manage the app's state.

## Future Scope

- Potential integration of **AI APIs** for live data processing.
- **Next.js** optimizations for performance improvements (SSR, static generation).
- Expansion of **interactive elements** with **GSAP** animations and advanced state management techniques in **React**.

## Installation

To get started with this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/HeAR-AI-Frontend.git
````

2. Navigate into the project directory:

   ```bash
   cd HeAR-AI-Frontend
   ```
3. Install dependencies:

   ```bash
   npm install
   ```
4. Run the development server:

   ```bash
   npm run dev
   ```

Visit `http://localhost:3000` in your browser to view the project.
